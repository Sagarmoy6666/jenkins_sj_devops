Title - This content explains the steps to install Jenkins.
Description -
This file contains the steps of the following activities. Completing this will let us use Jenkins.
A. Create an EC2 Instance.
B. Login to EC2 Instance.
C. Install Java.
D. Install Jenkins
E. Add Jenkins Repository & GPG Key
F. Install Jenkins.
G. Enable & Start Jenkins service.
H. Unlock Jenkins in the Web Browser.
I. Install Plugins.
J. Use Jenkins.
